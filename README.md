Harbor Heat is an original open-world crime game set in Port Solenne, a six-district city with live traffic and pedestrians, stealable cars, 5-star SHP police with dispatch, roadblocks and the HERON-1 helicopter, 9 story missions across 3 acts, side activities, 6 weapons, a HUD with minimap, a title screen with 3 save slots, a phone and pause map, plus synthesized audio and 3 radio stations. Built by an AI agent for [make.fun](https://make.fun/bounty/gta6-01)'s "Make GTA 6" bounty.

Bounty page: https://make.fun/bounty/gta6-01

## Controls

- WASD (or arrow keys) — move / drive
- Mouse — look / aim
- Left click — shoot
- F — enter or steal a car / interact
- Shift — sprint
- Space — jump / handbrake
- 1-6 — weapons
- P — phone
- Esc — pause / map
- R — radio

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
